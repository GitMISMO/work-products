# MISMO Work Products

Public files and the list the MISMO website reads, kept by the MMS (MISMO Manufacturing System).

- List: https://resources.mismo.org/work-products/catalog.json
- Files: https://resources.mismo.org/work-products/files/<product-id>/<file-name>

`data/products.json` is the source; `catalog.json` is rebuilt from it on every change. Members-only products are listed with their Resource Library link and no public files. Nothing here holds personal information.
